How the agent learns

The AI uses Deep Q-Learning: a small network (11 inputs → hidden layer → 3 outputs) estimates how good each of three moves is: go straight, turn right, or turn left. The browser version is a direct port of the Python code in this repository.

  • What it sees

    11 yes/no signals: danger straight, right or left; which way it is moving; and which way the food is.

  • Rewards

    +10 for eating, −10 for dying or looping too long, 0 otherwise. You can change these above.

  • Exploration

    It starts by making random moves, and these become rarer as it plays more games.

  • Replay memory

    It stores past moves and re-learns from a random batch of them after every game.

Run the Python version

pip install -r requirements.txt
python play.py                      # play with arrow keys / WASD
python train.py                     # train with a pygame window + live plot
python train.py --games 300 --no-render --no-plot   # fast headless run
python train.py --help              # every option (speed, lr, gamma, ...)
python export_model.py              # make model.pth loadable on this page
